## Що надруковано

**Критична швидкість з умови керованості:**
`V_кер = √[(√(φ²−f²)/tgθ − f)·g·L·cosθ]`, де `θ` — кут повороту керованих
коліс. Рахують при `θ = 5, 10, 15, 20, 25, 30, 35, 40°` і будують залежність
(рис. 9). Вище за `V_кер` керовані колеса ковзають у поперечному напрямі, і
поворот їх на більший кут не змінює напряму руху.

**Радіус повороту при еластичних колесах:**
`R_e = L/(tg(θ−δ₁) + tgδ₂)`, де `θ = 20°` — середній кут повороту;
`δ₁ = P_δ1/ΣK_від1`, `δ₂ = P_δ2/ΣK_від2` — кути бокового відведення.

Граничні бокові сили, за яких колеса котяться без бокового ковзання:
`P_δ1 = 0,4·P_φ1`, `P_δ2 = 0,4·P_φ2`, де `P_φ = φ·G` — сили зчеплення осей.

`K_від` — коефіцієнт опору боковому відведенню одного одинарного колеса:
**500…1000 Н/град** для легкового автомобіля, **800…1500 Н/град** для
вантажного.

**При жорстких колесах** `R = L/tgθ`.

**Тип поворотності:** `R_e = R` — нейтральна, `R_e > R` — недостатня,
`R_e < R` — надлишкова.

**Якщо поворотність надлишкова**, визначають критичну швидкість з умови
бокового відведення: `V_відв = √[gL/(G₂/ΣK_від2 − G₁/ΣK_від1)]`. Вона
**повинна на 20—30 % перевищувати максимальну швидкість** автомобіля.

## Допуску «майже нейтральна» джерело не подає

Джерело формулює три випадки через точну рівність і нерівності, без жодного
допуску. Спроба ввести власний поріг у два відсотки відразу дала суперечність:
крок називав поворотність нейтральною там, де другий критерій того самого
джерела — знак знаменника `V_відв` — бачив надлишкову.

Тому порівняння в документі **точне**, а наскільки далеко конструкція від
нейтральної, показує відношення `R_e/R`. Обидва критерії джерела тепер завжди
кажуть одне й те саме.
