## Що джерело просить описати, а не порахувати

Підрозділи **4.2.1** (джерело зве його «кістяк автомобіля»; документ уживає
сучасніший термін **несуча система**), **4.2.2 Мости** і **4.2.4 Колеса** не
містять **жодної формули**. Вони просять вибрати й обґрунтувати конструкцію та
накреслити схеми. Документ там нічого не рахує й каже про це прямо — так само,
як у §9.4.

## Характеристика пружних властивостей (4.2.3)

`Z_дин = (2…3)Z_ст` для доріг зі штучним покриттям, `(3…4)Z_ст` для ґрунтових
і бездоріжжя. `Z₀ = (0,6…0,7)Z_ст` — навантаження, за якого вмикається
додатковий пружний елемент.

`f_дин = (0,5…0,7)f_ст` для легкових, `(0,7…0,9)f_ст` для автобусів,
`(0,8…1,0)f_ст` для вантажних. **Статичний прогин той самий**, що прийнято в
розділі 3.5 (у документі — розділ 16) задля плавності ходу.

## Листова півеліптична ресора

Довжина ресори як частка бази — **три рядки, а не один**:

| Ресора | Частка від бази |
|---|---|
| Задні, легкові | 0,40…0,55 |
| Передні, вантажні | 0,26…0,35 |
| Задні, вантажні | 0,35…0,45 |

Текстова розшифровка подавала лише останній рядок; два інші відновлено з друку.

Коефіцієнти асиметрії `K₁ = l₂/L_р`, `K₂ = l₁/L_р`, причому `l₁ + l₂ = L_р`;
для симетричної `K₁ = K₂ = 0,5`.

`f_ст = δ·Z_ст·L_р³/(48EJ_Σ)` — симетрична, `f_ст = δ·Z_ст·l₁l₂/(3EJ_Σ·L_р)` —
несиметрична. `δ = 1,25…1,35` у вантажних, `1,35…1,40` у легкових;
`E = 210 ГПа`.

`J_Σ = b(h·n_л)³/12`, `n_л = 6…14`, `b/h = 6…10` → знаходять `h`, тоді `b`, і
порівнюють із ОН 8027-86 (таблиця 16).

## Формула суперечить власній таблиці джерела

`J_Σ = b(h·n_л)³/12` рахує пакет як **суцільну балку** завтовшки `h·n_л`.
Справжня ресора так не працює: листи ковзають один по одному, і пакет виходить
у рази м'якшим за суцільну балку тієї самої товщини — приблизно в `n_л²` разів.

Наслідок видно відразу. Для вантажного автомобіля з базою 3,3 м розрахунок дає
лист завтовшки **2,5 мм**, тимчасом як найтонший у таблиці 16 для цієї групи —
**6 мм**.

Документ рахує **надруковане** й показує обидва числа. Виправляти формулу
мовчки не можна; та й джерело саме тому й велить звірити результат із таблицею
та взяти лист із неї — саме там автор і мирить розрахунок зі стандартом.

## Доповнення: модель пакета ресори (Вахламов, с. 299)

Методичка друкує `J_Σ = b(h·n_л)³/12` — момент інерції **суцільної балки**
завтовшки в увесь пакет. Справжня ресора так не працює: листи ковзають один
по одному, кожен згинається сам по собі, і пакет виходить у рази м'якшим за
суцільну балку тієї самої товщини.

Ціна різниці перевіряється на фікстурі: за надрукованою формулою лист
виходить 2,5 мм, тобто **втричі тонший за найтонший у таблиці 16** — за той
самий стандарт, до якого та сама методичка велить його звіряти. Формула
суперечить власній таблиці джерела.

Вахламов (с. 299) подає прогин симетричної ресори як

```
f_р = δ·P_р·l_р³/(4·E·n_п·b·h³),   δ = 1,25…1,40
σ_изг = 1,5·P_р·l_р/(n_п·b·h²)
b — ширина листа; h — товщина листа
```

тобто рівно `n` листів паралельно: `J_Σ = n_л·b·h³/12`.

**Рішення проєкту:** пакет рахують як листи паралельно. Лист виходить
6…8 мм і потрапляє в таблицю 16. Те, що дала б надрукована формула,
показують поряд — на сторінці, у `readerNotes` кроку і в його `limitations`.
