# Витрата за їздовим циклом: паливо, електрика й їхня сума

## Початковий WLTC

Новий проєкт і скидання вибирають `wltc-auto`. Для звичайного ДВЗ
PMR = Pmax·1000/m₀, Вт/кг, де m₀ — споряджена маса проєкту без корисного
навантаження. Class 1: PMR ≤22, Class 2: 22<PMR≤34, Class 3: PMR>34.
Підклас 3a має Vmax<120 км/год, 3b — Vmax≥120 км/год. Категорія M2 не
означає WLTC Class 2. Для електричного й гібридного привода Class 3 —
порівняльне початкове припущення проєкту.

Повні базові профілі походять із [JRC WLTP](https://github.com/JRCSTU/wltp),
commit `18650f372044371ed994a161a93473a75e76d2a9`; вихідні точки,
метадані та EUPL-1.1 збережено в `external-data/JRC-WLTC`.
Class 1 триває 1611 с (low, medium, low); Class 2/3a/3b — 1800 с.
`scripts/build-cycle-presets.mjs` перевіряє довжину й контрольні суми JRC
та генерує CSV і браузерний модуль. Масштабування й обмеження швидкості
не застосовано. Для важких категорій це порівняльний профіль.

Автоматичний вибір слідує параметрам автомобіля. Явний вибір циклу,
власний CSV і вимкнення зберігаються при зміні категорії та імпорті JSON.
Навчальний цикл 60 с залишається окремим доступним пресетом.

## Дві паливні оцінки

(8.4) перетворює енергію §8.1–8.3 у літри за сталою питомою витратою
номінальної точки. (8.5) інтегрує витрату за передачами, обертами й

Це не означає, що (8.4) на 62,86% нижчий. Порівнюють лише повністю
покритий цикл; непораховані інтервали не перетворюють на нулі.

## Базова карта ефективності

Методичка карти двигуна не подає — вона подає питому витрату
`g_e = g_N·K_ω·K_B`, де `K_ω` залежить від відношення обертів до номінальних,
а `K_B` — від коефіцієнта використання потужності. **Це і є карта**, тільки
записана через витрату палива, а не через ККД.

Перехід між ними точний. За годину двигун віддає 1 кВт·год = 3,6 МДж і спалює
`g_e` грамів палива, у яких `H_u·g_e/1000` МДж хімічної енергії:

```
η_e = 3600/(g_e·H_u)      g_e у г/кВт·год, H_u у МДж/кг
```

Що вона дає (бензин, `g_N` = 250 г/кВт·год, `H_u` = 44 МДж/кг):

| Режим | `g_e`, г/кВт·год | `η_e` |
|---|---:|---:|
| номінальний | 250 | 33 % |
| `B` = 0,5, `ω/ω_N` = 0,8 | 251 | 32 % |
| `B` = 0,25, `ω/ω_N` = 0,6 | 415 | **20 %** |

Виражати модель джерела через ККД довелося не задля краси: **без нього літри
й кіловат-години не скласти**. Спаливши літр, двигун віддає не літр, а `η_e`
від його теплоти.

## Витрата за циклом (8.4)

```
Q_ц = E_ц·g_e/(ρ·10³) · 100/s_ц
```

**Чим це не є.** Питому витрату тут беруть сталою за цикл. У справжнього
двигуна вона змінюється з обертами й навантаженням, і сертифікаційна
процедура інтегрує карту двигуна по точках циклу, маючи для кожної точки
передачу з приписаного алгоритму перемикання. Тут передач за циклом не
розподіляють, отже й обертів не знають. Розділ 2 рахує усталений рух точніше:
там оберти відомі, і поправки `K_ω`, `K_B` застосовують.

## Стратегія гібрида (8.5)

Документ стратегію **не вигадує**: її задає автор двома числами.

* `x` — частка тягової енергії циклу, яку покриває електромашина;
* `ΔW_бат` — баланс заряду за цикл: нуль означає режим підтримання заряду,
  від'ємне число — розряд.

Решта — арифметика:

```
E_ел = E_ц·x
E_дв = E_ц·(1 − x) + (E_ел − ΔW_бат)/η_бат
```

Без цих двох чисел розділ відмовляється — але відмова тепер не глуха: поля
стоять поруч, і документ показує, що саме в них задано.

## Зведена витрата (8.6)

```
E_пал = E_дв/η_e          хімічна енергія, що заїхала в бак
Q = E_пал·3,6/(H_u·ρ)     вона ж у літрах
E_бат = −ΔW_бат           енергія, що заїхала з розетки
E_разом = E_пал + E_бат
```

Складають **первинну енергію на борту** — те, за що заплатили. Втрати
виробництва палива й електрики в жодне з чисел не входять, і це не
«еквівалентна витрата палива» сертифікаційних процедур: там електрику
переводять у літри за приписаним коефіцієнтом і зважують фази.

Що це дає на фікстурі (WLTC Class 3):

| Режим | л/100 км | кВт·год/100 км | разом, кВт·год/100 км |
|---|---:|---:|---:|
| без гібридизації | 6,45 | 0 | 59,1 |
| гібрид, підтримання заряду | 6,45 | 0 | 59,1 |
| PHEV, розряд 2 кВт·год | 3,58 | 8,59 | 41,4 |
| чиста електротяга | 0 | 19,34 | 19,3 |

## Найважливіше застереження

При **сталому** `η_e` гібрид у режимі підтримання заряду показує ту саму
витрату, що й звичайний автомобіль із тим самим двигуном. Це не хиба
розрахунку: батарея сама енергії не додає, вона лише перерозподіляє її в
часі, а віддати всю енергію циклу однаково мусить двигун.

Справжня вигода гібрида живе саме в карті ефективності: на чверті
навантаження ККД падає з 33 до 20 відсотків, і електромашина дозволяє не
працювати в цій зоні. Розрахунок за одним числом `g_N` цієї різниці не
показує й показати не може — щоб побачити її, треба задати, на якому
навантаженні працює двигун.

## Чого тут немає

* Миттєвого керування: частка електромашини стала на всьому циклі.
* Розподілу передач за циклом, отже й обертів двигуна.
* Вагування фаз, корекції балансу заряду й опору з вибігу — усього, що робить
  число витратою за WLTP.

Повноцінна фізична модель гібрида з картами двигуна, мотора, генератора й
батареї, з SOC і звіркою з реальними поїздками — окремий проєкт
(`Vehicle_simulation/My_PHEV`), і дублювати його тут не варто.

## Перевірка виконуваності та сума палива (v0.4.32)

Максимум профілю порівнюють із заданим Vmax незалежно від класу WLTC.
Class 3b має пік 131,3 км/год; для автомобіля з Vmax=120 км/год це окрема
невідповідність. Автоматичне обрізання або масштабування не виконується.

На кожному інтервалі перевіряють потрібну потужність, включно з інерцією.
Проєктна стратегія допускає пониження передачі; приписана — ні. При рушанні
оберти підбирають у межах характеристики за потрібним моментом, не нижче
синхронних обертів на кінцях інтервалу. Потужність ковзання додається до
потужності двигуна: Pковз=M(ωдв−ωвх), див.
[Disc Friction Clutch](https://www.mathworks.com/help/sdl/ref/discfrictionclutch.html).
Це квазістаціонарне проєктне припущення: окремої інерції розкручування ДВЗ
й теплової перевірки зчеплення тут немає. Для ковзання δ=1,04 враховує
обертові частини на колесах; для замкненого зчеплення δ залежить від передачі.

Неуспішний інтервал має fuelGrams=null. Решта циклу перевіряється й
інтегрується. Якщо повного покриття немає через нестачу тяги, крок
`drive-cycle-counted-fuel` показує суму відомих мас у літрах і покриту
відстань. Повного Qц у л/100 км він не створює. Джерело палива — поточна
карта цього автомобіля; коефіцієнти окремого Outlander PHEV не переносились.
