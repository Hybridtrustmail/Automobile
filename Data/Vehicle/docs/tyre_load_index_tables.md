# Tyre Load Index (ИНС) and Speed Category Tables

## Citation

Приходько В. М. (ред.). *Автомобильный справочник*. Москва, 2002.
Section «ИНДЕКС НЕСУЩЕЙ СПОСОБНОСТИ» / «ИНДЕКСЫ КАТЕГОРИЙ СКОРОСТИ»,
chapter *Механизмы управления. Ходовая часть* → *Колеса и шины*.

- **Таблица 12** — «ИНС / Нагрузка, кгс». Begins on printed page **205**, continues
  («Окончание») on printed page **206**.
- **Таблица 13** — «Индекс категории скорости / Скорость качения шины, км/ч».
  Printed page **206**.
- Local file: `Автомобили/Spravochnik/Avtomobil'nyj spravochnik  Prihod'ko_2002.compressed.pdf`
- **PDF page offset: +1.** Printed page 205 is PDF page 206; printed page 206 is
  PDF page 207. Transcribed from renders of PDF pages 206 and 207 at 300 dpi.

Values are given in **кгс** (kgf); numerically equal to kg of load per tyre.

## Dual-wheel convention

The handbook states (printed page 205):

> «Индекс несущей способности (ИНС) — цифровые коды, обозначающие максимальную
> нагрузку на шину, приведены в табл. 12, указываются как для одинарных, так и
> для сдвоенных колес (через дробь).»

So a tyre marking may carry two load indices separated by a slash, e.g. `98/96`:
the first for single-wheel fitment, the second (lower) for dual-wheel fitment.
A dual installation derates each tyre — when sizing for a dual-wheel axle, read
the second index.

## Origin of the system

**The handbook does not state that this is the international ETRTO/ISO system.**
Neither the two table sections nor the surrounding marking text (printed pages
204–206) names ETRTO, ISO or any national standard for these indices; the only
standards reference nearby is the «знак "E" официального утверждения … Правилам
ЕЭК ООН» item in the tyre-marking list. The transcription below therefore
reports the book's values as printed (with the corrections listed at the end),
without claiming a standards lineage the source does not assert.

## Transcription notes: corrections and defects

Every value was checked three ways: strict monotonicity across ИНС 0–199,
against independently verified anchors (0 = 45, 40 = 140, 80 = 450, 84 = 500,
100 = 800, 120 = 1400, 160 = 4500), and against the local step ratio (≈ 1.029).
After the corrections below, all 200 values are strictly increasing and every
step ratio lies within 1.015–1.045; no anchor disagrees.

### Errors in the printed book itself

These were read at 300 dpi from the scan and are **misprints in the source**,
not OCR damage. Each is corrected in the table above; the printed form is given
for traceability.

| ИНС | Printed | Corrected to | Why |
|---:|---:|---:|---|
| 72 | 655 | 355 | 71 = 345, 73 = 365; "655" breaks monotonicity outright |
| 85 | 545 | 515 | duplicates the value printed for 87; 84 = 500, 86 = 530 |
| 94 | index printed as `9` | 94 | row sits between 93 and 95; load 670 is correct |
| 107 | 985 | 975 | ИНС 100–108 run in uniform +25 steps (800, 825, … 950, **975**, 1000); 985 is the only break |
| 115 | 215 | 1215 | leading digit dropped; 114 = 1180, 116 = 1250 |
| 125 | 4650 | 1650 | 124 = 1600, 126 = 1700 |
| 152 | index printed as `52` | 152 | row sits between 151 and 153; load 3550 is correct |
| 190 | 1060 | 10600 | trailing digit dropped; 189 = 10300, 191 = 10900 |

### Errors introduced by the OCR only

The OCR text `Avtomobil'nyj spravochnik  Prihod'ko_2002.ocr.txt` (table at lines
≈20135–20195) interleaves the five column-pairs and mis-reads digits. Cases
where the OCR disagrees with the scan and **the scan is correct**:

### Unreadable

None. Every cell of both tables was legible at 300 dpi; no value in this
document is interpolated to fill an unreadable cell. The eight corrections above
are corrections of misprints whose intended value is fixed by both neighbours,
not reconstructions of missing data.
