## Передаточні числа (4.3.1)

`U_ω = α_р.к/α_к.к`, де `α_р.к = 540…1080°` — максимальний кут повороту
рульового колеса, `α_к.к = 35…40°` — керованого.

`U_p = ΣP_к.к/P_р.к = ΣM_к.к·R_р.к/(M_р.к·C)`; якщо знехтувати втратами на
тертя, `U_p = U_ω·R_р.к/C`.

`R_р.к = 0,20…0,25 м` — радіус рульового колеса; `C` — радіус обкочування:
**0,03…0,06 м** у легкових, **0,05…0,12 м** у вантажних.

**Силове передаточне число має лежати в межах 100…300.**

## Зусилля на кермі (4.3.2)

`P_р.к = ΣM_к.к/(U_ω·η_р.м·η_р.п·R_р.к)`, Н, де `η_р.м = 0,70…0,90` — ККД
рульового механізму, `η_р.п = 0,65…0,95` — ККД привода.

**Якщо зусилля при повороті коліс нерухомого автомобіля перевищує 400 Н, у
рульовому керуванні слід застосувати підсилювач.** Це головний висновок
розділу.

`ΣM_к.к ≈ 1,25·G·(f_пов·c + φ·r_ковз)`, Н·м, де `G` — сила тяжіння на керовані
колеса; `φ = 0,6…0,8`; `r_ковз ≈ (0,12…0,15)r_к`.

## Опір коченню тут — не той, що в розділі 2

Джерело позначає його тією самою літерою `f`, але це **інша величина**. У
документі вона має власний індекс — **`f_пов`**, — щоб однакове позначення
більше не зводило докупи дві різні речі.

Для повороту коліс **на місці** джерело подає власні числа:
`f_пов = 0,03…0,06` для автомобілів на дорогах із твердим покриттям і
`0,1…0,3` для тих, що працюють переважно на бездоріжжі.

Це не той коефіцієнт, з яким автомобіль **котиться** (розділ 2): колесо тут не
котиться, а розвертається на місці, стираючи протектор. Плутати їх не можна —
різниця сягає п'яти разів, і вона входить у момент опору прямо пропорційно.

## Рейковий механізм

`Z₁ = 6…10` — зубів шестерні; `P_n = πm` при `m = 3,0…3,5 мм`;
`Z = L/P_n + 0,5`; уточнена довжина `L = (Z − 0,5)P_n`;
`h = (2h_a* + c*)m` при `h_a* = 1,0`, `c* = 0,25`; `S̄_y = 0,5πm`.
