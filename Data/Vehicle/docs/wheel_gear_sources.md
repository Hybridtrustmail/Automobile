## Зуби

```
Z_по ≥ 12
Z_k = Z_по(U_p − 1)
```

Обчислене `Z_k` округляють до цілого числа, **кратного кількості сателітів**.

### Додаткова перевірка сумісності зубів

Самої кратності, наведеної S1, недостатньо. [KHK Gear Technical Reference,
§17.1](https://khkgears.net/new/gear_knowledge/gear_technical_reference/gear_systems.html)
задає для стандартної співвісної схеми `Z_k = Z_по + 2Z_c`, рівняння (17.1),
та умову рівномірного розміщення `(Z_по + Z_k)/n_c` — ціле, рівняння (17.3).
Проєкт зберігає задані центральну шестерню й кількість сателітів та відмовляє
в прийнятті кандидата, якщо сателіт має дробові зуби або не виконується
фазова умова складання. Наприклад, `Z_по = 14`, `Z_k = 21`, `n_c = 3`
задовольняє кратність S1, але вимагав би `Z_c = 3,5` зуба.

Це перевірка необхідних умов, а не повне підтвердження конструкції. Корекцію
профілю не задано; зазор між сусідніми сателітами, підрізання, інтерференцію
та міцність перевіряють окремо. Умови KHK звірено 24.09.2026 з текстом
виробника та зображенням формули (17.3).

## Міжосьова відстань

```
a_w ≥ K_a(U_p − 1)·√(Ω·K_H·M_по/(n_c·ψ_a·[σ]²))
K_a = 4950
Ω = 1,1…1,2      — коефіцієнт нерівномірності розподілу навантаження
K_H = 1,05…1,08  — коефіцієнт концентрації навантаження
M_по             — крутний момент на півосі
ψ_a = 0,5 при U_p ≤ 6,8;  0,4 при U_p > 6,8
[σ] = 1000 ГПа   — допустимі напруги
```

Ряд міжосьових відстаней: 40, 50, 63, 71, 80, 90, 100, 112, 125, 140, 160,
180, 200, 225, 250, 280, 315 мм.

```
b_2 = ψ_a·a_w
b_c = (1,04…1,05)b_2      — ширина вінця сателіта
b_по = (1,04…1,05)b_c     — ширина центральної шестірні
```

### Виправлення текстового шару

Djvu-транскрипт подавав тут поріг `U_p ≤ 6,3`. На зображенні сторінки чітко
**6,8**. У документі 6,8.

### Розбіжність 1: [σ] = 1000 ГПа

Одиниця помилкова. Тисяча гігапаскалів уп'ятеро більша за модуль пружності
сталі (≈200 ГПа), а напруга не буває більшою за нього.

Наслідок перевіряється числом: `[σ]` стоїть під коренем **у квадраті**, тому
тисяча разів у напрузі — це рівно тисяча разів у міжосьовій відстані. За
гігапаскалями `a_w` виходить у частках міліметра.

**Рішення проєкту:** читають МПа; відхилення названо в `readerNotes` кроку,
у `limitations` сліду й у тексті розділу.

### Розбіжність 2: «до найближчого» проти `a_w ≥ …`

Джерело велить округлювати до найближчого значення ряду і водночас пише
`a_w ≥ …`, тобто задає нижню межу. Ряд грубий, тому найближче значення часто
виявляється меншим за розрахункове, і нерівність порушується.

**Рішення проєкту:** беруть перше значення ряду, яке нерівність задовольняє;
найближче показують поряд, і крок каже, чому вони різні. Це рішення прийнято
й пояснено в кроці, тому діагностики про нього немає.

### Спостереження про надруковані сталі

За надрукованими `K_a = 4950` і `[σ] = 1000` МПа результат виходить угорі
ряду або за ним: при `U_p = 3`, `n_c = 3` ряд вичерпується вже на
`M_по ≈ 1240` Н·м, а типова колісна передача має `a_w` близько 60…100 мм.
Що саме тут не так — сталá, форма кореня чи щось третє — з джерела не
випливає, і документ нічого не домислює: рахує як надруковано, а коли ряд не
сягає потрібного, каже про це діагностикою
`WHEEL_GEAR_CENTRE_OUT_OF_SERIES`. Рисунок 23.1 показує ту саму залежність.

## Модуль

```
D_по = 2Z_по·1/(U_p + 1)     ← так надруковано
m = D_по/Z_по
```

Обчислений модуль округляють до найближчого з ряду таблиці 15.

### Розбіжність 3: у чисельнику має бути a_w, а не Z_по

Перевірено на фрагменті сторінки при 600 dpi: у друку справді стоїть
`Z_по`. Це неправильно, і показати це можна двома незалежними способами.

**Розмірність.** `2Z_по/(U_p + 1)` — чисте число, а `D_по` — діаметр.

**Наслідок.** Модуль вийшов би `m = D_по/Z_по = 2/(U_p + 1)` — однаковий для
будь-якої передачі з таким передаточним числом, хоч для легковика, хоч для
самоскида, і незалежний навіть від числа зубів. Для `U_p = 3` кожна колісна
передача у світі мала б `m = 0,5` мм. А міжосьова відстань, порахована
рядком вище, не знадобилася б узагалі — ланцюг обірвався б.

Співвідношення для пари із зовнішнім зачепленням (рис. 26, а):
`a_w = m(Z_1 + Z_2)/2 = m·Z_по(1 + U_p)/2`, звідки `D_по = m·Z_по =
2a_w/(U_p + 1)`.

Однак це не геометрія планетарної схеми з нерухомою коронною шестернею,
передаточне число якої вже прийняте як `U = 1 + Z_k/Z_по`.
За співвісною умовою `Z_c = (Z_k - Z_по)/2`:

```
a_w = m(Z_по + Z_c)/2 = m(Z_по + Z_k)/4
m_потр = 4a_w,min/(Z_по + Z_k)
D_по = m Z_по = 4a_w,факт/U_факт
```

**Рішення проєкту:** попередню відстань залишають нижньою геометричною
вимогою; приймають перший модуль ряду не менший за потрібний. Після цього
фактичні діаметри всіх трьох коліс, міжосьову відстань і ширини визначають
за прийнятим модулем та цілими зубами. Якщо ряд модулів недостатній,
модуль не приймають. Рівняння (23.3) і (23.4) показують цю узгоджену
геометрію; надруковане безрозмірне значення лишається лише для звірки.

## Чого в джерелі немає

* Передаточне число редуктора `U_p`, кількість сателітів `n_c` і число зубів
  центральної шестірні (понад «не менше 12») джерело залишає за автором.
* Рис. 26 подає чотири кінематичні схеми, але формули далі не розділені за
  ними: `Z_k = Z_по(U_p − 1)` — співвідношення для схеми з коронною
  шестірнею, а `D_по = 2a_w/(U_p + 1)` — для пари із зовнішнім зачепленням.
  Документ веде ланцюг за стандартною співвісною планетарною схемою з
  нерухомою коронною шестернею; зовнішню пару з цим передаточним числом
  не змішує. Геометрична узгодженість не є перевіркою міцності.
* Розрахунку зубів на згин і на контактну витривалість для колісної передачі
  джерело не подає.
